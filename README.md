# 🛡️ SecureWise

### Digital Safety Academy | Learn Wisely. Stay Secure.

**SecureWise** is a bilingual, interactive digital safety education website designed to help everyday internet users understand cybersecurity threats and develop safer online habits.

The platform combines an elegant, technology-inspired interface with accessible educational content and practical knowledge challenges. Its mission is to make digital security approachable for everyone, regardless of age or technical experience.

## ✨ Features

- **Bilingual Experience:** Seamless switching between English and Portuguese, with language preferences saved locally.
- **Interactive Cybersecurity Quiz:** 10 real-world scenarios featuring instant feedback, explanations, and a final score.
- **Educational Modules:** Six essential digital safety topics with actionable security recommendations.
- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices.
- **Premium UI/UX:** A sophisticated visual identity featuring amethyst purple, metallic silver, deep blue, and black.
- **Accessibility Features:** Semantic HTML, keyboard focus indicators, accessible navigation, and reduced-motion support.
- **No Registration Required:** Educational content and quizzes are available without creating an account.

## 📚 Educational Topics

1. **Phishing Awareness** — Recognizing suspicious messages, fraudulent links, and social engineering tactics.
2. **Password Security** — Creating strong, unique passwords and using password managers.
3. **Account Protection** — Understanding multi-factor authentication and verification codes.
4. **Digital Privacy** — Managing personal information and online privacy.
5. **Online Banking Safety** — Identifying financial scams and protecting financial accounts.
6. **Device Security** — Applying software updates, screen locks, and safer connection practices.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YasmimStephanie/securewise.git
   ```

2. Open the project directory:

   ```bash
   cd securewise
   ```

3. Open `index.html` in your browser or run the project using the **Live Server** extension in Visual Studio Code.

No installation, build process, or backend server is required.

## 🌍 Language Support

SecureWise supports:

- 🇺🇸 English
- 🇧🇷 Português (Brasil)

Users can switch languages using the **EN / PT** buttons in the navigation bar. The selected language is stored in the browser's local storage and automatically restored on future visits.

## 🧠 Interactive Learning

The cybersecurity quiz presents 10 multiple-choice questions based on realistic digital safety situations.

Users receive immediate feedback after each answer, including an explanation of the recommended security practice.

At the end, the platform displays their final score and allows them to restart the challenge.
